# Historias de usuario

Las historias de usuario describen las principales necesidades desde la perspectiva de quien utilizará el sistema, siguiendo el formato:

> Como **[actor]**, quiero **[acción]**, para **[beneficio]**.

## Listado de historias de usuario

| ID | Historia de usuario |
| --- | --- |
| HU01 | Como administrado, quiero consultar los requisitos, costos y plazos de un trámite, para saber qué necesito antes de iniciar el procedimiento. |
| HU02 | Como administrado, quiero recibir orientación paso a paso para iniciar un trámite, para completarlo correctamente y reducir errores en la presentación. |
| HU03 | Como administrado, quiero consultar el estado de mi expediente, para saber en qué etapa se encuentra y qué pasos siguen. |
| HU04 | Como administrado, quiero interactuar con el asistente por texto o voz desde WhatsApp, para usarlo desde mi celular sin necesidad de acudir presencialmente. |
| HU05 | Como administrado, quiero recibir una respuesta con la cita del documento que respalda la información, para confiar en lo que me indica el asistente. |
| HU06 | Como administrado, quiero ser atendido por un gestor cuando el asistente no tiene certeza, para resolver casos que requieren criterio humano. |
| HU07 | Como gestor de área, quiero recibir en mi bandeja los casos derivados con un borrador de respuesta, para revisarlos y aprobarlos con menor esfuerzo. |
| HU08 | Como gestor de área, quiero actualizar el catálogo de trámites de mi área (requisitos, costos, plazos y base legal), para mantener la información al día sin depender del área de TI. |
| HU09 | Como gestor de área, quiero validar los borradores de respuesta generados por el asistente, para asegurar la calidad antes de que lleguen al administrado. |
| HU10 | Como autoridad o administrador, quiero consultar indicadores de demanda y trámites más consultados, para tomar decisiones sobre recursos y atención. |
| HU11 | Como autoridad o administrador, quiero visualizar los expedientes con plazos vencidos o en riesgo, para priorizar la atención y reducir la morosidad. |
| HU12 | Como autoridad o administrador, quiero ver indicadores de satisfacción y motivos de derivación, para mejorar continuamente el catálogo y los flujos del asistente. |
